PDF Table Extractor
功能描述： 这是一个基于浏览器的纯前端工具，用于从 PDF 文件中提取表格数据并转换为 Excel 格式。

核心技术：

Tailwind CSS: UI 样式。

PDF.js: 解析和渲染 PDF。

SheetJS (XLSX): 生成并下载 Excel 文件。

如何使用：

在浏览器中打开 index.html。

上传 PDF 文件。

点击 "Open Editor" 进入编辑界面。

点击 "Extract Tables" 提取数据，确认无误后点击 "Save Excel"。
