# Temp Testing

### 📝 功能描述
这是一个临时测试工具，包含温度转换功能，可以在华氏度和摄氏度之间进行转换。

### 🌡️ 温度转换功能
- **功能**: 用户可以在华氏度或摄氏度输入框中输入任意一个温度值，点击"Convert"按钮后，另一个输入框会自动计算并更新对应的温度值。
- **转换公式**:
  - 摄氏度转华氏度: F = C × 9/5 + 32
  - 华氏度转摄氏度: C = (F - 32) × 5/9
- **界面**: 全部使用英语，提供清晰的输入框和转换结果显示。

### 如何使用
1. 在浏览器中打开 `index.html`。
2. 点击"启动测试工具"按钮。
3. 在新窗口中输入华氏度或摄氏度中的任意一个值。
4. 点击"Convert"按钮进行转换。
5. 转换结果会显示在另一个输入框中，并在下方显示转换公式。

### 技术栈
* **Tailwind CSS**: 用于快速构建美观的响应式 UI 界面。
