# Excel Side-by-Side Viewer v2.0

### 📝 功能增强
这是一个专为复杂财务数据设计的并排对比工具。

### 🚀 新增核心功能
* **多列联合对比**: 支持选择多个列作为匹配基准，适合处理具有复杂索引的表格。
* **滚动锁定 (Scroll Lock)**: 开启后，左右两个表格会同步滚动，极大方便了行对行的核对工作。
* **智能匹配算法**: 引入了子序列匹配逻辑，即使两个表格的描述文字略有差异（如“现金”与“现金及等价物”），也能尝试进行关联。
* **紧凑型 UI**: 压缩了行高和边距，在有限的屏幕空间内展示更多财务数据。

### 如何使用
1. 在浏览器中打开 `index.html`。
2. 点击“启动查看工具”。
3. 上传两份表格，选择对应的标题行。
4. **重要**: 依次点击选择需要比较的列（注意两侧选择的顺序需一致）。
5. 勾选“滚动锁定”进行同步核对。
