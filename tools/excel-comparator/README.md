# Excel Side-by-Side Viewer (Excel 并排查看工具)

### 📝 功能描述
这是一个专门为财务分析师设计的工具，用于并排对比两个 Excel 工作表的数据差异。

### 核心功能
* **双表对比**: 同时上传两个 Excel 文件（.xlsx, .xls, .csv）。
* **智能对齐**: 支持手动选择标题行和关键比较列。
* **差异高亮**: 
    * 🟢 绿色：数据完全匹配。
    * 🔴 红色：数据存在差异或缺失。
* **自定义布局**: 支持拖动中间的分隔条来调整左右表格的显示宽度。

### 核心技术
* **XLSX (SheetJS)**: 处理浏览器端的 Excel 解析。
* **Tailwind CSS**: 响应式布局和 UI 设计。
* **JavaScript (Vanilla)**: 纯原生 JS 实现的对比算法。

### 如何使用
1. 在浏览器中打开 `index.html`。
2. 点击“启动查看工具”打开新窗口。
3. 分别上传需要对比的两个表格。
4. 选定标题行和比较列后，点击“开始比较”。
